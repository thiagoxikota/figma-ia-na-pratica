# handoff

Pasta para o workshop das 20h. Leve como está, na Área de Trabalho, com o nome `handoff`.

| Arquivo | O que é |
|---|---|
| `tokens.json` | Os tokens de design no formato W3C Design Tokens, iguais às variáveis da coleção Workshop Tokens do arquivo do Figma |
| `tokens.css` | Os mesmos tokens convertidos em variáveis CSS |
| `config.json` | A configuração do Style Dictionary, a ferramenta que converte o `tokens.json` |
| `Card.html` e `Card.css` | Um card em HTML puro que usa esses tokens. Abra o `Card.html` no navegador para ver |
